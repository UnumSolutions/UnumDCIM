# Security policy

## Reporting a vulnerability

Email security@unumsol.com. You will receive an acknowledgement within 5 working days. Please do not open public issues for security reports.

## Supported versions

There are no releases yet. Once releases exist, security fixes are backported to the current release and the two previous minor releases (N-2) and to every supported LTS line.

## Disclosure

We follow coordinated disclosure. Fixes are published with a CVE where applicable, and release artifacts are signed with Sigstore and shipped with an SPDX/CycloneDX SBOM.

## Machine-readable contact

See `.well-known/security.txt` (RFC 9116).
